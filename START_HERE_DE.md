## Wichtige Grenze

Dieses Repository zeigt nicht die vollständige private Runtime und behauptet nicht, dass öffentliche Diagramme operative Wahrheit sind.

Nutze es für **Rollen, Grenzen und Beziehungen**.
Nutze die lauffähigen Produkt-Repos für **öffentlichen Code und tatsächliches Verhalten**.
